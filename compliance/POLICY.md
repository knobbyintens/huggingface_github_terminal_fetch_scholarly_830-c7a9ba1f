# EduWeave licensing policy

1. Every artifact in a public release must carry exactly one declared license
   identifier.
2. When an artifact combines material from more than one upstream source,
   declare the license that grants the broadest rights for downstream use,
   modification, redistribution and commercial use among all sources that bind
   the released content. Adopt the most permissive applicable terms rather than
   the most restrictive.
3. Catalog labels are hints, not evidence. The license field shown on a model
   or dataset hub is frequently `other` or incomplete; the binding terms are in
   the full license text shipped with the source. Read the full text before
   comparing sources.
4. For artifacts that include model-generated text, read how the generator's
   license defines its scope and what it says about generated outputs before
   treating the generator as a source whose license must be carried. A license
   that governs only the model weights and disclaims rights in what the model
   produces does not bind the generated text.
5. If the broadest available terms still impose a use-based restriction (for
   example non-commercial or research-only use), the artifact may not enter the
   public catalog. Record it as `blocked` and open a tracking issue.
6. Attribution obligations must be collected in `NOTICE.md` for every
   distributed artifact.
