# EduWeave-Study

`EduWeave-Study` is a research instruction set prepared for the internal
EduWeave evaluation round. It is derived from **tatsu-lab/alpaca**
(https://huggingface.co/datasets/tatsu-lab/alpaca) and includes the
instruction/input/output records shipped by that source, lightly re-formatted.

It is listed as a candidate for the v0.3 public catalog.

- Rows: 52,002 instruction records
- Format: JSONL
- Upstream: tatsu-lab/alpaca
